# Refined FollowUp Design System & Screens

This directory contains the polished and expanded design assets for the FollowUp SaaS platform. All components have been updated to strictly adhere to the brand guidelines (Navy #1A2B4C, Emerald #48C78E, Inter Font).

## 1. Updated Design System Components
- **`StatusBadge.jsx`**: Refined badges for Paid, Overdue, Sent, and Pending status using brand-aligned color weights.
- **`StatsCard.jsx`**: Polished KPI cards with brand iconography, subtle backgrounds, and growth indicators.
- **`InvoiceTable.jsx`**: Refined data table with optimized spacing, Navy headers, and clear typography.
- **`Dashboard.jsx`**: A full layout of the main dashboard including a brand-aligned Sidebar, Header, and integrated components.

## 2. New Pages & Screens
- **`Settings.jsx`**: A comprehensive settings interface for Managing Firm Profile, Notifications, Subscription, and Automation Preferences.
- **`InvoiceImport.jsx`**: An intuitive UI for adding invoices via Bulk CSV upload or Manual entry, including a brand-styled Info section.
- **`ClientPortal.jsx`**: A public-facing, secure invoice view for clients. Features include an urgent overdue notice, Action buttons (Mark as Paid/Download PDF), and a Document Upload section.

## Usage
These components are designed to be used in a React environment with Tailwind CSS. They use `lucide-react` for iconography.

### Brand Constants
- **Primary (Navy)**: `#1A2B4C`
- **Secondary (Emerald)**: `#48C78E`
- **Background (Ghost White)**: `#F8FAFC`
- **Accent (Danger Red)**: `#E53E3E`
- **Typography**: Inter (Regular 400, Bold 700, Black 900)
